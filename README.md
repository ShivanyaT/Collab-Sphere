# Collab-Sphere

Collab-Sphere is a beginner-friendly open-source platform where developers can **collaborate**, **create**, and **contribute** to exciting tech projects. It’s designed to help users start new projects, explore existing ones, and chat with team members in a simple, user-friendly interface.

---

## 🚀 Features

-  Explore community-driven projects
-  Start your own open-source project
-  Team chat interface
-  Login functionality with remember me
-  Feedback submission support
-  Dark mode toggle
